# Supplier List

หน้า **Supplier List** ใช้จัดการรายชื่อผู้ให้บริการยานพาหนะภายนอก (Supplier) ที่บริษัทใช้งาน

เข้าถึงได้จาก **Setting → Vehicle → Supplier List**

---

## ตารางรายการ

<div className="manual-img-500">

![Supplier List](/img/Vehicle/supplier-list.png)

</div>

ตารางแสดงรายการ Supplier ทั้งหมด ประกอบด้วยคอลัมน์ดังนี้

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Image** | รูปโปรไฟล์ |
| **Supplier Name** | ชื่อ Supplier (คลิกได้เพื่อดูรายละเอียด) |
| **Group Type quantity** | จำนวนประเภทรถที่ผูกไว้ (คลิกได้) |
| **Status** | สถานะการใช้งาน |
| | <span class="badge badge-active">Active</span> เปิดใช้งาน |
| | <span class="badge badge-inactive">Inactive</span> ปิดใช้งาน |
| **Last Modify Date** | วันที่แก้ไขล่าสุด |
| **Action** | ปุ่ม `...` สำหรับจัดการ |

---

## ฟังก์ชันบนหน้า

| ปุ่ม | คำอธิบาย |
|------|----------|
| **Create Supplier** | สร้าง Supplier ใหม่ |
| **Search** | ค้นหา Supplier |
| **Filter** | กรองข้อมูลตามเงื่อนไข |
| **Export** | ดาวน์โหลดรายชื่อ Supplier |

---

## ตัวกรอง

<div className="manual-img-500">

![Vehicle Supplier Filter](/img/Filter/filter-vehicle-supplier-modal.png)

</div>

กดปุ่ม **Filter** เพื่อเปิด Modal กรองข้อมูลตามเงื่อนไขที่ต้องการ

| ฟิลด์ | คำอธิบาย |
|-------|----------|

กด **Search** เพื่อค้นหา หรือ **Clear all** เพื่อล้างเงื่อนไข

### Supplier Login

<div className="manual-img-500">

![Create Supplier - Supplier Login](/img/Vehicle/supplier-create-login.png)

</div>

สร้างบัญชีสำหรับ Supplier Login เพื่อให้ Driver ของ Supplier เข้าสู่ระบบตรวจสอบงานได้

| ฟิลด์ | คำอธิบาย | จำเป็น |
|-------|----------|:------:|
| **Username** | ชื่อบัญชีเข้าสู่ระบบ | ✅ |
| **Password** | รหัสผ่าน | ✅ |
| **Confirm Password** | ยืนยันรหัสผ่าน | ✅ |

กด **Save** เพื่อบันทึกข้อมูลทั้งหมดและสร้าง Supplier

:::tip เคล็ดลับ
สามารถกด **Save and exit** ในขั้นตอนที่ 1 เพื่อบันทึกข้อมูลทั่วไปก่อน แล้วกลับมาสร้าง Supplier Login ภายหลังได้
:::

## View

คลิกที่ชื่อ Supplier หรือกดปุ่ม `...` → **View** เพื่อดูรายละเอียด

หน้า View แบ่งเป็น 4 แท็บ ปุ่ม **Edit** อยู่มุมขวาบนของหน้า

:::caution ข้อควรระวัง
ในโหมด View จะ**ไม่สามารถแก้ไขข้อมูล**ได้ — หากต้องการแก้ไขให้กดปุ่ม **Edit** ภายในหน้า View
:::

### General Detail

<div className="manual-img-500">

![Supplier View - General Detail](/img/Vehicle/supplier-view-general.png)

</div>

แสดงข้อมูลทั่วไปของ Supplier ได้แก่ รูปโปรไฟล์, ชื่อ, ข้อมูลติดต่อ, ที่อยู่, Arrangement Type, Bank Detail และ Group Type ที่ผูกไว้

- **Status** — เปลี่ยนสถานะ Active / Inactive ได้จากหน้า View โดยตรง

---

### Supplier Login

<div className="manual-img-500">

![Supplier View - Supplier Login](/img/Vehicle/supplier-view-login.png)

</div>

แสดงข้อมูลบัญชีที่ใช้ Login ระบบ

| ฟิลด์ | คำอธิบาย |
|-------|----------|
| **Username** | ชื่อบัญชีเข้าสู่ระบบของ Supplier |
| **Password / Confirm Password** | แสดงเป็น `••••••••` (ไม่เปิดเผยรหัสผ่าน) |

---

### Registration

<div className="manual-img-500">

![Supplier View - Registration](/img/Vehicle/supplier-view-registration.png)

</div>

แสดงรายการทะเบียนรถของ Supplier ทั้งหมด

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Registration** | เลขทะเบียนรถ |
| **Group Type** | ประเภทรถที่ผูกไว้ |
| **Active** | Toggle เปิด/ปิดการใช้งาน |
| **Action** | ปุ่มจัดการ (แก้ไข / ลบ) |

#### Add Registration

<div className="manual-img-500">

![Add Registration](/img/Vehicle/supplier-add-registration.png)

</div>

1. กดปุ่ม **Add Registration** มุมขวาบนของแท็บ
2. กด **Add group type** เพื่อเปิด Modal เลือกประเภทรถ

<div className="manual-img-500">

![Add Group Type Modal](/img/Vehicle/supplier-add-group-type-modal.png)

</div>

3. เลือก **Group Type** ที่ต้องการ (เลือกได้หลายรายการ) แล้วกด **Confirm**
4. กรอกหมายเลขทะเบียนรถสำหรับแต่ละ Group Type ที่เลือก
5. กด **Save** เพื่อบันทึก หรือ **Cancel** เพื่อยกเลิก

:::tip เคล็ดลับ
สามารถกด **Add group type** ซ้ำได้เพื่อเพิ่มทะเบียนรถหลายประเภทในครั้งเดียว
:::

---

### Personnel list

<div className="manual-img-500">

![Supplier View - Personnel list](/img/Vehicle/supplier-view-personnel.png)

</div>

แสดงรายชื่อบุคลากร (Driver / Guide) ของ Supplier

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Image** | รูปโปรไฟล์ |
| **Position** | ตำแหน่ง เช่น Driver |
| **Name** | ชื่อบุคลากร (คลิกได้เพื่อดูรายละเอียด) |
| **Phone Number** | เบอร์โทรศัพท์ |
| **Registration** | ทะเบียนรถที่ผูกไว้ |
| **Action** | ปุ่มจัดการ (แก้ไข / ลบ) |

#### Add Personnel

<div className="manual-img-500">

![Add Personnel](/img/Vehicle/supplier-add-personnel.png)

</div>

1. กดปุ่ม **Add Personnel** มุมขวาบนของแท็บ
2. กรอกข้อมูลในฟอร์ม

| ฟิลด์ | คำอธิบาย | จำเป็น |
|-------|----------|:------:|
| รูปโปรไฟล์ | อัปโหลดรูปบุคลากร | — |
| **Position** | ตำแหน่งงาน (dropdown) | ✅ |
| **Name** | ชื่อ-นามสกุลบุคลากร | ✅ |
| **Phone Number** | เบอร์โทรศัพท์ | ✅ |
| **Email** | อีเมล | — |
| **Registration** | เลขทะเบียนรถที่มอบหมาย (dropdown) | — |

3. กด **Save** เพื่อบันทึก หรือ **Cancel** เพื่อยกเลิก

## Edit

กดปุ่ม **Edit** ภายในหน้า View เพื่อเข้าสู่โหมดแก้ไข

<div className="manual-img-500">

![Supplier Edit - General Detail](/img/Vehicle/supplier-edit-general.png)

</div>

หน้า Edit มีโครงสร้าง 4 แท็บเหมือนกับหน้า View ทุกประการ สามารถแก้ไขข้อมูลได้ในทุกแท็บ

| แท็บ | สิ่งที่แก้ไขได้ |
|------|----------------|
| **General Detail** | ข้อมูลทั่วไป, Bank Detail, Group Type |
| **Supplier Login** | Username, Password (Reset Password) |
| **Registration** | เพิ่ม / แก้ไข / ลบทะเบียนรถ |
| **Personnel list** | เพิ่ม / แก้ไข / ลบบุคลากร |

1. แก้ไขข้อมูลในแท็บที่ต้องการ
2. กด **Save** เพื่อบันทึก หรือ **Cancel** เพื่อยกเลิก
