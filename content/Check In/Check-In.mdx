# Check In

หน้า **Check In** ใช้สำหรับเช็คอินลูกค้าที่มาถึงในวันเดินทาง โดยกรอก Booking ID หรือสแกน QR Code เพื่อยืนยันการเข้าร่วม

เข้าถึงได้จาก **Check In → Check In** ในเมนูหลัก

---

ด้านขวาของช่องกรอก Booking ID จะแสดงป้าย **Checking in as • Transport** (สีเขียว) เพื่อยืนยันประเภทที่เลือก

## วิธีใช้งาน

| ช่องทาง | คำอธิบาย |
|---------|----------|
| **Excursion / Transport** | เลือกประเภทที่ต้องการ Check In จากแท็บด้านบน |
| **Enter Booking ID** | พิมพ์เลข Booking ID แล้วกดปุ่ม **Check In** |
| **QR Code Scanner** | กดไอคอนสแกนเนอร์ (ด้านขวาของช่องกรอก) เพื่อสแกน QR Code จาก Booking |

---

## ขั้นตอนการ Check In

1. เลือกประเภท **Excursion** หรือ **Transport** จากแท็บด้านบน
2. พิมพ์ **Booking ID** ในช่องกรอก หรือกดไอคอนสแกนเพื่อสแกน QR Code
3. ระบบจะแสดงข้อมูลลูกค้าและ Booking ที่ตรงกัน
4. ตรวจสอบข้อมูลให้ถูกต้อง (ชื่อลูกค้า, โปรแกรม, จำนวน Pax)
5. กดปุ่ม **Check In** เพื่อยืนยัน
6. ระบบจะอัปเดตสถานะเป็น **Checked In** ทันที

:::caution ข้อควรระวัง
เมื่อกด Check In แล้ว สถานะจะเปลี่ยนทันที กรุณาตรวจสอบข้อมูลและประเภท (Excursion / Transport) ให้ถูกต้องก่อนยืนยัน
:::
