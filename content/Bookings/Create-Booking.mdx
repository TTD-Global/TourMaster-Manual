# Create Booking

หน้า **Create Booking** ใช้สำหรับสร้าง Booking ใหม่ให้ลูกค้า

กดปุ่ม **Create Booking** จากหน้า Booking List เพื่อเข้าสู่หน้านี้

---

<Tabs>
  <TabItem value="form" label="สร้าง Booking" default>

![Create Booking](/img/Bookings/booking-create-form.png)

---

## Booking Details

เลือก **Booking Travel Date** (วันที่เดินทาง) ที่มุมขวาบนก่อน แล้วกรอกข้อมูลส่วน Booking Details

| ฟิลด์ | คำอธิบาย | จำเป็น |
|-------|----------|:------:|
| **Seller** | Seller หรือตัวแทนที่รับจอง (dropdown) | ✅ |
| **Booking No.** | เลขที่ Booking | ✅ |
| **Program Name** | ชื่อโปรแกรมทัวร์ (dropdown) | ✅ |
| **Payment** | ประเภทการชำระเงิน (dropdown) | — |
| **Option** | Option เพิ่มเติม (dropdown) | — |
| **Trip Type** | ประเภท Trip (dropdown) | ✅ |
| **Trip round** | รอบเวลา Trip (dropdown) | ✅ |
| **Language** | ภาษาที่ต้องการ (dropdown) | — |

## Unit Details

ส่วน **Unit Details** แสดงรายการบริการที่รวมอยู่ใน Program ที่เลือก (โหลดอัตโนมัติหลังเลือก Program Name)

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **Unit** | ชื่อรายการบริการ |
| **Price** | ราคาต่อหน่วย |
| **Quantity** | จำนวน (กรอกได้) |
| **KB** | ราคา KB |
| **Total** | ราคารวมของรายการนั้น |

สรุปยอดท้ายส่วน Unit Details

| รายการ | คำอธิบาย |
|--------|----------|
| **Sub total** | ราคารวมก่อนหักส่วนลด |
| **Discount** | ส่วนลด (กรอกได้) |
| **Total Pax** | จำนวนผู้เดินทางรวม |
| **Total KB** | ยอดรวม KB |
| **Total Price** | ราคารวมสุทธิ (บาท) |

## บันทึก Booking

| ปุ่ม | คำอธิบาย |
|------|----------|
| **Clear Form** | ล้างข้อมูลทั้งหมดในฟอร์ม |
| **+ Create Booking** | บันทึก Booking ด้วยสถานะ **Reserved** |
| **Create & Confirm** | บันทึกและยืนยัน Booking ทันที (สถานะ **Confirmed**) |

:::tip เคล็ดลับ
ควรสร้าง Seller, Program และ Trip round ใน Setting ก่อน เพื่อให้มีข้อมูลให้เลือกในฟอร์ม
:::

## All Bookings

![All Bookings](/img/Bookings/booking-create-all.png)

ส่วนด้านล่างของหน้า Create Booking แสดงรายการ Booking ที่มีอยู่แล้วในวัน **Booking Travel Date** เดียวกัน แบ่งออกเป็น 2 กลุ่ม

| ข้อมูลสรุป | คำอธิบาย |
|-----------|----------|
| **Total Booking** | จำนวน Booking ทั้งหมด |
| **Total Pax** | จำนวนผู้เดินทางรวม |
| **Total Income** | ยอดรวมรายได้ |

กดปุ่ม **Route Summary** เพื่อดูสรุปเส้นทางของวันนั้น

---

### Join In Booking

Booking แบบ Join In — ลูกค้าหลายกลุ่มร่วม Trip เดียวกัน

### Private Booking

Booking แบบ Private — ลูกค้าจอง Trip เป็นของตัวเอง

ทั้งสองตารางแสดงคอลัมน์เดียวกัน

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Seller** | ชื่อ Seller |
| **Travel Date** | วันที่เดินทาง |
| **Booking Date** | วันที่สร้าง Booking |
| **Booking No.** | เลขที่ Booking |
| **Trip Round** | รอบของ Trip |
| **Program** | ชื่อโปรแกรม |
| **Pax** | จำนวนผู้เดินทาง |
| **Trip Code** | รหัส Trip |
| **Status** | สถานะ Booking |
| **Action** | ปุ่มจัดการ |
