# Balance

**Balance** คือหน้าสรุปยอดเงินคงเหลือของแต่ละ Trip เปรียบเทียบระหว่างเงิน Advance ที่เบิกไปกับค่าใช้จ่ายจริงที่เกิดขึ้น

เข้าถึงได้จาก **Payment → Balance**

---

## ตารางรายการ

![Balance](/img/Payment/payment-balance-list.png)

### Summary Card

ด้านบนแสดง Card สรุปภาพรวม

| Card | คำอธิบาย |
|------|----------|
| **Amount Trip** | จำนวน Trip ทั้งหมด |
| **Total Advance** | ยอดเงิน Advance รวม |
| **Total Actual** | ยอดค่าใช้จ่ายจริงรวม |
| **Return to company** | ยอดเงินที่ต้องคืนบริษัท (Advance > Actual) |
| **Company pays additional** | ยอดที่บริษัทต้องจ่ายเพิ่ม (Actual > Advance) |

### แท็บสถานะ

| แท็บ | คำอธิบาย |
|------|----------|
| **Pending** | Trip ที่ยังรอดำเนินการ |
| **Completed** | Trip ที่ดำเนินการเสร็จแล้ว |

### คอลัมน์ตาราง

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Trip Code** | รหัส Trip |
| **Trip Type** | ประเภท Trip (เช่น Join In) |
| **Program** | ชื่อโปรแกรม |
| **Guide** | ชื่อ Guide ที่รับผิดชอบ |
| **Adv.Pax** | จำนวน Pax ที่ใช้คำนวณ Advance |
| **Adv.Cost** | ยอดเงิน Advance |
| **Act.Pax** | จำนวน Pax ที่เกิดขึ้นจริง |
| **Expense** | ยอดค่าใช้จ่ายจริง |
| **Balance** | ยอดคงเหลือ (Adv.Cost − Expense) |
| **Slip** | หลักฐานการโอนเงิน / สลิป |
| **Action** | ปุ่มจัดการ |

---

## การตีความ Balance

| ผลลัพธ์ | ความหมาย |
|---------|----------|
| **Balance > 0** (บวก) | Advance มากกว่า Expense → Guide คืนเงินส่วนเกิน |
| **Balance = 0** | ค่าใช้จ่ายตรงกับ Advance พอดี |
| **Balance < 0** (ลบ) | Expense เกิน Advance → บริษัทจ่ายเพิ่มให้ Guide |

## Action

กดปุ่ม `...` ในคอลัมน์ **Action** เพื่อจัดการรายการ

### View

แสดงรายละเอียดสรุปยอดเงินของ Trip นั้น เปรียบเทียบ Advance กับ Expense จริงในแต่ละหมวดหมู่

![Balance View](/img/Payment/payment-balance-view.png)

#### Guide Information

สรุปข้อมูล Pax สำหรับ Trip นี้

| Card | คำอธิบาย |
|------|----------|
| **Pax No.ADV** | จำนวน Pax ที่ใช้คำนวณ Advance (ตอนจองล่วงหน้า) |
| **Checked In** | จำนวน Pax ที่ Check In จริง |
| **No show** | จำนวน Pax ที่ไม่มาตามนัด |
| **Amount Pax Act.** | จำนวน Pax จริงที่ใช้คำนวณค่าใช้จ่าย |

#### Expense

ตารางเปรียบเทียบ Advance กับ Expense จริงรายการต่อรายการ

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Items** | รายการค่าใช้จ่าย |
| **Payment** | ประเภทการชำระ |
| **Cost Type** | ประเภทการคำนวณ (Person / Car / Trip) |
| **Cost (Unit)** | ราคาต่อหน่วย |
| **Adv.Pax** | จำนวน Pax ที่ใช้คำนวณ Advance |
| **Adv.Cost** | ยอด Advance ต่อรายการ |
| **Act.Pax** | จำนวน Pax จริง |
| **Expense** | ยอดค่าใช้จ่ายจริงต่อรายการ |
| **Balance** | ผลต่าง (Adv.Cost − Expense) ต่อรายการ |

#### Summary

| รายการ | คำอธิบาย |
|--------|----------|
| **Advance Paid** | ยอดเงิน Advance ที่เบิกไปทั้งหมด |
| **Actual Expense** | ยอดค่าใช้จ่ายจริงทั้งหมด |
| **Balance** | ผลต่างสุดท้าย (Advance − Actual Expense) |

#### Slip / Attachment

| ส่วน | คำอธิบาย |
|------|----------|
| **Expense Attachment** | อัปโหลดสลิปหลักฐานค่าใช้จ่าย |
| **Balance Attachment** | อัปโหลดสลิปการโอนเงินคืน / รับเพิ่ม |

ปุ่มที่มีใน View:
- **Approve** — อนุมัติรายการ Balance
- **Edit** — เข้าสู่โหมดแก้ไข
- **Close** — ปิดหน้า View

:::info เงื่อนไขการแสดงข้อมูลใน Balance
Trip จะปรากฏใน Balance ได้ก็ต่อเมื่อมีข้อมูลครบทั้ง **Advance** และ **Expenses**

- หาก Program ใช้เฉพาะ **Credit** (ไม่มี Advance) หรือมีเฉพาะ **Expenses** โดยไม่มี Advance — Trip นั้นจะ**ไม่ปรากฏ**ใน Balance
- Balance คำนวณอัตโนมัติจากข้อมูล Advance และ Expenses ที่บันทึกไว้ สามารถดูสรุปภาพรวมทุก Trip ได้ใน **Report**
:::
