# Advance

**Advance** คือหน้าจัดการเงินเบิกล่วงหน้าสำหรับ Guide และ Driver แต่ละ Trip ก่อนออกเดินทาง

เข้าถึงได้จาก **Payment → Advance**

---

## ตารางรายการ

![Advance](/img/Payment/payment-advance-list.png)

### Summary Card

ด้านบนแสดง Card สรุปภาพรวม

| Card | คำอธิบาย |
|------|----------|
| **Amount Trip** | จำนวน Trip ทั้งหมด |
| **Total Advance** | ยอดเงิน Advance รวม |
| **Total Extra Advance** | ยอดเงิน Extra Advance รวม |
| **Total** | ยอดรวมทั้งหมด (Advance + Extra Advance) |

### แท็บสถานะ

| แท็บ | คำอธิบาย |
|------|----------|
| **Pending** | Trip ที่ยังรอดำเนินการ |
| **Completed** | Trip ที่ดำเนินการเสร็จแล้ว |

### คอลัมน์ตาราง

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **#** | ลำดับที่ |
| **Trip Code** | รหัส Trip |
| **Travel Date** | วันที่เดินทาง |
| **Trip Type** | ประเภท Trip (เช่น Join In) |
| **Trip Round** | รอบเวลาเดินทาง |
| **Program** | ชื่อโปรแกรม |
| **Guide** | ชื่อ Guide ที่รับผิดชอบ |
| **Bank Detail** | ข้อมูลบัญชีธนาคารของ Guide (เลขบัญชี, ชื่อเจ้าของบัญชี) |
| **Pax** | จำนวนผู้เดินทาง |
| **Advance** | ยอดเงินเบิกล่วงหน้า |
| **Extra Advance** | ยอดเงินเบิกเพิ่มเติม |
| **Total** | ยอดรวม (Advance + Extra Advance) |
| **Action** | ปุ่มจัดการ |

แถวสุดท้ายแสดง **Total** รวม Advance, Extra Advance, Total ทั้งหมด

## Action

กดปุ่ม `...` ในคอลัมน์ **Action** เพื่อจัดการรายการ

### View

แสดงรายละเอียดรายการ Advance ของ Trip นั้น แยกตามประเภทค่าใช้จ่าย

![Advance View](/img/Payment/payment-advance-view.png)

#### Guide Information

ส่วนบนสุดแสดงข้อมูล Guide ที่รับผิดชอบ Trip นี้ รวมถึงข้อมูลบัญชีธนาคารสำหรับการโอนเงิน

#### Cash Advance

ตารางรายการเงินเบิกล่วงหน้าแยกตามประเภท

| ส่วน | คำอธิบาย |
|------|----------|
| **Guide** | รายการค่าจ้าง Guide แยกตาม Item |
| **Other Expense** | รายการค่าใช้จ่ายอื่นๆ เช่น ค่าเข้าชม, ค่าอาหาร |
| **Extra Cost** | รายการค่าใช้จ่ายพิเศษจาก Option เพิ่มเติม |

ทุกตารางมีคอลัมน์: **#** / **Items** / **Cost Type** / **Cost (Unit)** / **Pax** / **Advance Cost**

#### Summary

| รายการ | คำอธิบาย |
|--------|----------|
| **Total Advance Cost** | ยอดรวม Advance ทั้งหมด |
| **Extra Advance** | ยอดเงิน Advance พิเศษที่เพิ่มเติม |
| **Total** | ยอดรวมสุดท้าย (Total Advance Cost + Extra Advance) |

ปุ่มที่มีใน View:
- **Approve** — อนุมัติรายการ Advance
- **Edit** — เข้าสู่โหมดแก้ไข
- **Close** — ปิดหน้า View

---

### Edit และการเพิ่ม Extra Advance

**Extra Advance** คือรายการเงินเบิกพิเศษที่ Guide ขอเพิ่มเติมนอกเหนือจาก Advance ปกติ เช่น ค่าใช้จ่ายที่เกิดขึ้นกะทันหัน

![Advance Edit](/img/Payment/payment-advance-edit.png)

#### ขั้นตอนการเพิ่ม Extra Advance

1. กดปุ่ม `...` → **Edit** (หรือเปิด View แล้วกด **Edit**)
2. เลื่อนลงมาที่ส่วน **Extra Advance** ด้านล่าง แล้วกดปุ่ม **Add extra advance**

![Add extra advance button](/img/Payment/payment-advance-extra-button.png)

3. แถวใหม่จะปรากฏในตาราง Extra Advance

![Extra Advance Form](/img/Payment/payment-advance-extra-form.png)

4. กรอกข้อมูลในแถวที่เพิ่มขึ้นมาใหม่:

| ฟิลด์ | คำอธิบาย | จำเป็น |
|-------|----------|--------|
| **Items** | รายการค่าใช้จ่าย (เลือกจาก dropdown) | ✅ |
| **Cost Type** | ประเภทการคำนวณ (Person / Car / Trip) | ✅ |
| **Cost (Unit)** | ราคาต่อหน่วย | ✅ |
| **Pax** | จำนวนหน่วย (คน / คัน / เที่ยว) | ✅ |

5. กด **Save** เพื่อบันทึก

:::info
**Advance Cost** คำนวณอัตโนมัติจาก Cost (Unit) × Pax สามารถเพิ่มได้หลายแถวโดยกด **Add extra advance** ซ้ำ
:::

:::info
Advance ที่ **Approve** แล้วยังสามารถกด **Edit** เพื่อแก้ไขได้ สถานะจะยังคงเป็น **Completed** เหมือนเดิมหลังการแก้ไข
:::
