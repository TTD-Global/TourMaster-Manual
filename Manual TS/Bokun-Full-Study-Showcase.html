WHAT IS BÓKUN

Bókun รวม 3 อย่างไว้ในระบบเดียว

จากการทดลองสร้างสินค้าจริง ("Bangkok Temple Walking Tour") ตั้งค่า Availability/Pricing และใช้ Quick Book จริง

1

Booking Engine

จองและจัดการ Availability กับ Pricing ของสินค้าทัวร์

2

Channel / Inventory Manager

เอาสินค้าชิ้นเดียวไปขายพร้อมกันหลายช่องทาง Sync สต๊อกอัตโนมัติ ไม่ให้ Overbook

3

CRM + เครื่องมือขาย

เก็บข้อมูลลูกค้า มี Promo code มีระบบรับเงินในตัว

WHY IT WORKS

ทำไมบริษัททัวร์ถึงอยากใช้ Bókun

1

หาลูกค้าใหม่หลายช่องทาง

Booking widget, OTA (Viator, GetYourGuide, Airbnb), Marketplace 2,000+ ราย

2

ไม่ต้องมีทีม IT

SaaS พร้อมใช้ สมัครแล้วขายได้เลย เหมาะกับ Operator เล็ก-กลาง

3

ลด Overbooking

Sync สต๊อกข้ามทุกช่องทางขายอัตโนมัติ

4

เครื่องมือขายครบ

Promo code, Commission group, Payment ในตัว, AI ช่วยเขียนคำโฆษณา

5

เชื่อม Viator ลื่นไหล

เพราะเป็นเจ้าของเดียวกับ TripAdvisor

Bókun ตอบโจทย์ Operator ที่อยากขายได้มากขึ้น ผ่านช่องทางหลากหลายขึ้น โดยลงทุนน้อยที่สุด
WHY TRIPADVISOR ACQUIRED IT

TripAdvisor เข้าซื้อ Bókun — 20 เมษายน 2018

เติมเต็มฝั่ง Supply ที่ TripAdvisor ขาด ไม่ใช่ขยายฐานลูกค้า

Supply-side Gap

แข็งด้าน Demand แต่ขาดเครื่องมือฝั่ง Supply

มีนักท่องเที่ยวเข้ามาดูรีวิว/ค้นหาทัวร์เยอะอยู่แล้ว แต่ไม่มีเครื่องมือช่วย Operator จัดการสินค้า สต๊อก และราคา

Digital Onboarding

ดึง Operator รายเล็กเข้าสู่ระบบดิจิทัล

Operator จำนวนมากยังจัดการด้วยมือหรือสเปรดชีต Bókun ช่วยดึงสินค้าเข้าแพลตฟอร์มได้ง่ายขึ้น

Inventory Control

ควบคุม Inventory แบบ Real-time เอง

ได้ Channel Manager ผูกตรงกับ Supplier แทนที่จะพึ่ง OTA เจ้าอื่นเป็นตัวกลาง

พูดง่ายๆ TripAdvisor ไม่ได้ซื้อ Bókun เพื่อขยายฐานลูกค้า แต่ซื้อเพื่อเติมเต็มเทคโนโลยีฝั่ง Supply/Operator ให้ครบวงจร

SYSTEM COMPARISON

Bókun เทียบกับ DMC และ Tour System

DMC = B2B/Wholesale ปิด  ·  Tour System = Operations/Cost Control ภายใน  ·  Bókun = B2B2C Distribution เปิดกว้าง

Bókun

แพลตฟอร์มขาย + จัดจำหน่าย เน้นหาลูกค้าและปิดการขาย

  • Storefront + Quick Book, Pay now/Already paid/Pay later
  • Booking widget, OTA, Marketplace 2,000+ ราย
  • CRM นักท่องเที่ยว, Promo code, Payment ในตัว
  • 6 Role สำเร็จรูปทั่วไป ไม่มี KPI พนักงาน
DMC System + Tour System

ระบบภายในสำหรับจัดหาสินค้า บริหารคู่ค้า และควบคุมปฏิบัติการ/ต้นทุน

  • ทุก Booking ผูกกับ Agent เสมอ ไม่มีหน้าขายตรงถึงผู้บริโภค
  • Agent 16 ราย / Supplier 230 ราย ที่ทำสัญญาแล้ว
  • Grouping → รถ/ไกด์ → Job Order → Check-in → ปิดต้นทุนจริง
  • Enterprise Role (Admin/Manager/Accounting/BD/CS&RSVN/MD) + KPI พนักงาน
DETAILED COMPARISON

เจาะลึกความต่างทีละหมวด

Bókun vs DMC System

โครงสร้างสินค้าและช่องทางขาย

ทั้งคู่มีแนวคิดพื้นฐานคล้ายกัน คือสินค้าไปเป็น Package แล้วไป Booking แล้วไป Operations แต่ต่างกันที่แก่นของกลุ่มเป้าหมาย

  • กลุ่มเป้าหมายBókun ทั้ง B2C และ B2B ผ่าน Marketplace ส่วน DMC เป็น B2B ล้วน
  • โครงสร้างสินค้าBókun ใช้ Experience + Pricing categories + Auto FX ส่วน DMC ใช้ Product → Package → Unit แบ่งด้วย B2B/B2C flag
  • ช่องทางขายBókun มี Widget, OTA, Marketplace เปิดกว้าง ส่วน DMC ไม่มีช่องทางสาธารณะเลย
Bókun vs DMC System

คู่ค้า สิทธิ์ และการวัดผล

DMC ลึกกว่าชัดเจนในมุมองค์กรและการควบคุมภายใน

  • Agent/SupplierBókun เป็น Marketplace เปิด จับคู่ใหม่ได้เรื่อยๆ ส่วน DMC มี Agent 16 ราย / Supplier 230 ราย ที่ทำสัญญาแล้ว
  • Role/สิทธิ์DMC มี Enterprise Role ตรงกับโครงสร้างองค์กรจริง ที่ Bókun ไม่มี
  • KPI พนักงานDMC มี Performance Evaluation วัดผลรายคน Bókun ไม่มีฟีเจอร์นี้เลย
Bókun vs Tour System

การสร้าง Booking และปฏิบัติการหน้างาน

Bókun มี 2 เส้นทางสร้าง Booking พร้อมตัวเลือกชำระเงิน ส่วน Tour System เน้นความละเอียดปฏิบัติการ

  • สร้าง BookingBókun มี Storefront + Quick Book พร้อม Pay now/Already paid/Pay later ส่วน Tour System ใช้ฟอร์มเดียวจบ ผูก Itinerary/Cost ล่วงหน้า
  • ปฏิบัติการหน้างานTour System ผูก Booking เข้ากับ Grouping รถ ไกด์ Job Order Check-in ในระบบเดียว ขณะที่ Bókun มีแค่ Passenger list/Pick-up list ระดับพื้นฐาน
  • รายงาน/การเงินBókun มองจากช่องทางขาย ส่วน Tour System มองจากต้นทุนปฏิบัติการ (Advance, Expense, Balance)
Bókun vs Tour System

ช่องทางขายและเครื่องมือขาย

นี่คือจุดต่างที่ใหญ่ที่สุดระหว่าง Bókun และ Tour System

  • การกระจายสินค้าBókun มี Booking widget, OTA, Marketplace 2,000+ ราย, Referral link ส่วน Tour System ไม่มีแนวคิดช่องทางขายเลย
  • CRM ลูกค้าBókun เก็บประวัติ/อีเมลนักท่องเที่ยวทุกคน Tour System เก็บเฉพาะข้อมูลผู้ใช้งานภายใน
  • User RolesBókun มี 6 Role สำเร็จรูป ใกล้เคียงกับ Roles/Permissions ของ Tour System
THE VERDICT

รวม DMC + Tour System สู้ Bókun ได้ไหม

คำตอบ: สู้ได้บางส่วน แบบมีเงื่อนไข ไม่ใช่สู้ได้เต็มรูปแบบ

แข็งแรงกว่าจริง

ปฏิบัติการ + ต้นทุน + ความสัมพันธ์ B2B — DMC ควบคุมราคาส่ง Agent/Supplier จริง Tour System ผูก Grouping/รถ/ไกด์/Job Order/ปิดต้นทุนจริงในระบบเดียว Bókun มีแค่ระดับพื้นฐานเท่านั้น

ยังสู้ไม่ได้

หาลูกค้าใหม่ + ขายตรงผู้บริโภค + Marketplace — ทั้งสองระบบไม่มี Storefront ไม่เชื่อม OTA ไม่มี CRM ผู้บริโภค ไม่มีระบบรับเงินออนไลน์

ข้อสรุป

เทียบหลังบ้านต่อหลังบ้าน เราดีกว่าจริง แต่เทียบแพลตฟอร์มขายต่อแพลตฟอร์มขาย เรายังไม่มีของชิ้นนั้นเลยแม้รวมสองระบบ

STRATEGIC OPTIONS

ทางเลือกเชิงกลยุทธ์ที่เป็นไปได้

1

ไม่แข่งตรง

วางตำแหน่งเป็นเครื่องยนต์หลังบ้านที่แข็งแกร่งที่สุด รับสินค้า/Booking จาก Bókun หรือ OTA อื่นมาบริหารต่อ

2

สร้างชั้นขายเพิ่ม

ลงทุนพัฒนา B2C/Storefront/Payment ใหม่ ต่อยอดของเดิม เพื่อแข่งกับ Bókun ตรงๆ ใช้ทรัพยากรและเวลามาก

3

ผสมทั้งสองแบบ

เปิดช่องทางขายเฉพาะกลุ่มเล็ก ใช้จุดแข็งด้านต้นทุนและปฏิบัติการรักษาฐาน Agent เดิมไว้

Bókun vs DMC + Tour System

Bókun เก่งเรื่องขายและกระจายสินค้า  ·  DMC + Tour System เก่งเรื่องปฏิบัติการและควบคุมต้นทุนแบบ B2B
