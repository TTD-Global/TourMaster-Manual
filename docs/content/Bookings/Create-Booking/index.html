Create Booking

หน้า Create Booking ใช้สำหรับสร้าง Booking ใหม่ให้ลูกค้า

กดปุ่ม Create Booking จากหน้า Booking List เพื่อเข้าสู่หน้านี้

  • สร้าง Booking
  • All Bookings

ภาพรวมหน้า​

Booking Details​

เลือก Booking Travel Date (วันที่เดินทาง) ที่มุมขวาบนก่อน แล้วกรอกข้อมูลส่วน Booking Details

ฟิลด์คำอธิบายจำเป็น
SellerSeller หรือตัวแทนที่รับจอง (dropdown)✅
Booking No.เลขที่ Booking✅
Program Nameชื่อโปรแกรมทัวร์ (dropdown)✅
Paymentประเภทการชำระเงิน (dropdown)—
OptionOption เพิ่มเติม (dropdown)—
Trip Typeประเภท Trip (dropdown)✅
Trip roundรอบเวลา Trip (dropdown)✅
Languageภาษาที่ต้องการ (dropdown)—

Customer Details​

ฟิลด์คำอธิบายจำเป็น
Customer Nameชื่อลูกค้า✅
Nationalityสัญชาติของลูกค้า—
Emailอีเมลลูกค้า—
Phone numberเบอร์โทรลูกค้า—
Contact methodช่องทางการติดต่อ (dropdown)—

Unit Details​

ส่วน Unit Details แสดงรายการบริการที่รวมอยู่ใน Program ที่เลือก (โหลดอัตโนมัติหลังเลือก Program Name)

คอลัมน์คำอธิบาย
Unitชื่อรายการบริการ
Priceราคาต่อหน่วย
Quantityจำนวน (กรอกได้)
KBราคา KB
Totalราคารวมของรายการนั้น

สรุปยอดท้ายส่วน Unit Details

รายการคำอธิบาย
Sub totalราคารวมก่อนหักส่วนลด
Discountส่วนลด (กรอกได้)
Total Paxจำนวนผู้เดินทางรวม
Total KBยอดรวม KB
Total Priceราคารวมสุทธิ (บาท)

Location Details​

ฟิลด์คำอธิบายจำเป็น
Meeting point locationสถานที่นัดพบ—
Pick up locationสถานที่รับลูกค้า—
Pick-up timeเวลารับลูกค้า—
Pick-up addressที่อยู่สำหรับรับลูกค้า—
Drop - off pointจุด Drop-off ที่ต้องการ—
Drop - off remarkหมายเหตุเพิ่มเติมเกี่ยวกับ Drop-off—
ข้อควรระวัง

หาก Trip Type เป็น Excursion หรือ Join In ฟิลด์ Pickup (Meeting point location, Pick up location, Pick-up time, Pick-up address) จะไม่แสดงขึ้นมาให้กรอก

Remark​

ฟิลด์คำอธิบายจำเป็น
Remarkข้อความพิเศษหรือความต้องการพิเศษของลูกค้า—

บันทึก Booking​

ปุ่มคำอธิบาย
Clear Formล้างข้อมูลทั้งหมดในฟอร์ม
+ Create Bookingบันทึก Booking ด้วยสถานะ Reserved
Create & Confirmบันทึกและยืนยัน Booking ทันที (สถานะ Confirmed)
เคล็ดลับ

ควรสร้าง Seller, Program และ Trip round ใน Setting ก่อน เพื่อให้มีข้อมูลให้เลือกในฟอร์ม

All Bookings​

ส่วนด้านล่างของหน้า Create Booking แสดงรายการ Booking ที่มีอยู่แล้วในวัน Booking Travel Date เดียวกัน แบ่งออกเป็น 2 กลุ่ม

ข้อมูลสรุปคำอธิบาย
Total Bookingจำนวน Booking ทั้งหมด
Total Paxจำนวนผู้เดินทางรวม
Total Incomeยอดรวมรายได้

กดปุ่ม Route Summary เพื่อดูสรุปเส้นทางของวันนั้น

Join In Booking​

Booking แบบ Join In — ลูกค้าหลายกลุ่มร่วม Trip เดียวกัน

Private Booking​

Booking แบบ Private — ลูกค้าจอง Trip เป็นของตัวเอง

ทั้งสองตารางแสดงคอลัมน์เดียวกัน
