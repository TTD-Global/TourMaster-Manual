Expenses

Expenses คือหน้าบันทึกค่าใช้จ่ายที่เกิดขึ้นจริงระหว่างการดำเนินทริป เปรียบเทียบกับเงิน Advance ที่เบิกไว้

เข้าถึงได้จาก Payment → Expenses

ตารางรายการ​

Summary Card​

ด้านบนแสดง Card สรุปภาพรวม

Cardคำอธิบาย
Amount Tripจำนวน Trip ทั้งหมด
Total Advanceยอดเงิน Advance รวม
Total Expenseยอดค่าใช้จ่ายจริงรวม
Totalยอดรวมทั้งหมด

แท็บสถานะ​

แท็บคำอธิบาย
PendingTrip ที่ยังรอดำเนินการ
CompletedTrip ที่ดำเนินการเสร็จแล้ว

คอลัมน์ตาราง​

คอลัมน์คำอธิบาย
#ลำดับที่
Trip Codeรหัส Trip
Trip Typeประเภท Trip (เช่น Join In)
Trip Roundรอบเวลาเดินทาง
Programชื่อโปรแกรม
Guideชื่อ Guide ที่รับผิดชอบ
Bank Detailข้อมูลบัญชีธนาคารของ Guide
Paxจำนวนผู้เดินทาง
Advanceยอดเงินเบิกล่วงหน้า
Expenseยอดค่าใช้จ่ายจริง
Actionปุ่มจัดการ

ฟังก์ชันบนหน้า​

ปุ่ม / ฟังก์ชันคำอธิบาย
Date Filterกรองรายการตามวันที่
Exportส่งออกรายการ Expenses เป็นไฟล์

Action​

กดปุ่ม ... ในคอลัมน์ Action เพื่อจัดการรายการ

View​

แสดงรายละเอียดค่าใช้จ่ายจริงของ Trip นั้น แยกตามประเภท

Guide Information​

ส่วนบนแสดงสรุปจำนวน Pax

Cardคำอธิบาย
Pax No.ADVจำนวน Pax ที่ใช้คำนวณ Advance (ตอนจองล่วงหน้า)
Checked Inจำนวน Pax ที่ Check In จริง
No showจำนวน Pax ที่ไม่มาตามนัด
Amount Pax Act.จำนวน Pax จริงที่ใช้คำนวณค่าใช้จ่าย

Expense​

ตารางรายการค่าใช้จ่ายจริงแยกตามประเภท

ส่วนคำอธิบาย
Guideค่าจ้าง Guide จริง
Vehicle Costค่าใช้จ่ายยานพาหนะ (Supplier หรือ Own Vehicle)
Other Expenseค่าใช้จ่ายอื่นๆ เช่น ค่าเข้าชม, ค่าอาหาร

ทุกตารางมีคอลัมน์: # / Items / Cost Type / Cost (Unit) / Pax / Expense Cost

Summary​

รายการคำอธิบาย
Guideค่าใช้จ่ายส่วน Guide รวม
Vehicleค่าใช้จ่ายส่วนยานพาหนะรวม
Other Expenseค่าใช้จ่ายอื่นๆ รวม
Total Cost (THB)ยอดค่าใช้จ่ายจริงทั้งหมด

ปุ่มที่มีใน View:

  • Approve — อนุมัติรายการ Expenses
  • Edit — เข้าสู่โหมดแก้ไข
  • Close — ปิดหน้า View

Edit และการเพิ่ม Extra Expense​

Extra Expense คือรายการค่าใช้จ่ายพิเศษที่เกิดขึ้นระหว่าง Trip นอกเหนือจากที่วางแผนไว้ เช่น ค่าอาหารพิเศษ, ค่าใช้จ่ายฉุกเฉิน

ขั้นตอนการเพิ่ม Extra Expense​

  1. กดปุ่ม ... → Edit (หรือเปิด View แล้วกด Edit)
  2. เลื่อนลงมาที่ส่วน Extra Expense ด้านล่าง แล้วกดปุ่ม Add extra expense

  1. หน้าต่าง Add Extra Expense จะปรากฏขึ้น — กดที่ช่อง Items Type เพื่อเลือกประเภทรายการ

  1. กรอกข้อมูลในฟอร์ม:
ฟิลด์คำอธิบายจำเป็น
Items Typeประเภทรายการค่าใช้จ่าย (เลือกจาก dropdown)✅
Remarkหมายเหตุเพิ่มเติม—
Cost Typeวิธีคิดราคา (All / Person / Fix)✅
Cost (THB)ราคา (บาท)✅

  1. กดปุ่ม Add Item หากต้องการเพิ่มหลายรายการในครั้งเดียว
  2. กด Confirm เพื่อยืนยัน หรือ Cancel เพื่อยกเลิก
  3. กด Save เพื่อบันทึกการแก้ไขทั้งหมด

รายการ Extra Expense จะปรากฏในตาราง Extra Expense ด้านล่างพร้อมยอดรวมที่อัปเดตอัตโนมัติ

เคล็ดลับ

ระบบจะนำข้อมูล Expenses ไปคำนวณยอดคงเหลือให้อัตโนมัติใน Balance

info

Expenses ที่ Approve แล้วยังสามารถกด Edit เพื่อแก้ไขได้ สถานะจะยังคงเป็น Completed เหมือนเดิมหลังการแก้ไข
